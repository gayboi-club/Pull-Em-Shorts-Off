# Privacy Policy for Pull Em Shorts Off

**Last updated:** February 8, 2026

## Overview

Pull Em Shorts Off is a browser extension that helps users avoid endless scrolling on YouTube Shorts. This privacy policy explains what data the extension collects and how it is used.

## Data Collection

### What We Collect

The extension stores the following data **locally on your device only**:

- **User preferences**: Display name, notification time, homepage settings
- **Discord webhook URL**: If you choose to enable Discord notifications
- **Custom GIF URL**: If you set a custom replacement image

### What We Do NOT Collect

- We do not collect any personal information
- We do not track your browsing history
- We do not send any data to external servers (except Discord webhooks you configure)
- We do not use analytics or tracking

## Data Storage

All data is stored locally using the browser's built-in storage API (`browser.storage.local`). This data never leaves your device unless you configure Discord notifications.

## Discord Notifications

If you enable Discord notifications:
- A message is sent to a Discord webhook URL **that you provide**
- The only data sent is your display name and a motivational message
- No other personal data is transmitted

## Third-Party Services

- **YouTube**: The extension runs on YouTube pages to block Shorts scrolling
- **Discord**: Only if you configure a webhook for notifications
- **Tenor**: Default GIF is loaded from Tenor (you can change or disable this)

## Your Rights

You can:
- Disable or uninstall the extension at any time
- Clear all stored data by removing the extension
- Choose not to use Discord notifications

## Changes

This privacy policy may be updated. Any changes will be reflected in the extension update.
